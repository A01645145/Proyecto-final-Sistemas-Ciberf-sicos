# Proyecto-final-Sistemas-Ciberf-sicos

En este repositorio se encuentran todos los códigos para el desarrollo de un robot AMR. 

El principal objetivo del proyecto es generar un robot autónomo móvil con 4 ruedas mecanum capaz de de navegar en diversos espacios y transportar material, además de interactuar con personas y otros robots (cobots) de manera segura.
